# Data licenses and attribution

## BANC connectome

FlyArena's current topology target is BANC materialization v888 with the v3
compiled directed edge list. The full raw data and generated FlyArena cache are
not intended to be committed to the normal source repository.

The BANC project asks users to cite both:

- Bates AS, Phelps JS, Kim M, Yang HHJ, et al. “Distributed control circuits
  across a brain-and-cord connectome.” *Nature* 656, 957–970 (2026).
  DOI: https://doi.org/10.1038/s41586-026-10735-w
- BANC v888 data and analysis-code deposit, Harvard Dataverse.
  DOI: https://doi.org/10.7910/DVN/7WTH1N

The BANC project repository states that its code and the Dataverse data deposit
are released under Creative Commons Attribution 4.0 (CC BY 4.0). Archives inside
the deposit may carry their own notices; consult their per-archive documentation.

FlyArena-generated `.farena`, `.fio`, telemetry, and `.flytrain` files are
derived/local runtime artifacts. Their presence does not change the license of
the underlying BANC data.
