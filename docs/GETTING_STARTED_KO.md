# FlyArena 시작 안내

## 이 프로그램은 무엇인가요?

FlyArena는 초파리 뇌의 모든 생리를 완벽히 재현하는 프로그램이 아닙니다.
BANC v888에서 측정된 신경 연결 구조를 바탕으로 두 신경 상태를 계산하고,
FlyArena가 가정한 신경 동역학과 감각·운동 연결을 물리 전투장에 붙인 실험형
시뮬레이션입니다.

- 측정 자료: BANC의 뉴런과 연결 구조
- 추론한 모델: LIF 신경 동역학, 감각 입력, 운동 출력 연결
- 게임 규칙: 보상, 스태미나, 검·날개·방패 균형

## 가장 빠른 실행 방법

1. GitHub Releases에서 Windows x64 ZIP을 받습니다.
2. 원하는 폴더에 압축을 풉니다.
3. `prepare_banc_latest.bat`으로 BANC 캐시를 준비합니다. Python과 인터넷
   연결이 필요할 수 있으며 원자료의 라이선스는 `DATA_LICENSES.txt`에서
   확인할 수 있습니다.
4. `prepare_v061_io_map.bat`으로 입출력 맵을 준비합니다.
5. `FlyArena.exe`를 실행합니다.

BANC 원자료와 생성 캐시는 용량 및 라이선스 구분 때문에 배포 ZIP과 Git에
들어 있지 않습니다. 한 번 생성한 캐시는 매 라운드 다시 읽지 않으며, 같은
실행 세션의 반복 학습은 메모리와 GPU 상태를 재사용합니다.

## 화면의 주요 기능

- `CREATE FLY`: 검, 날개, 방패와 외형을 정해 `.flypack`으로 저장합니다.
- `TRAINING`: 가소성 readout을 학습하고 `.flytrain`에 저장합니다.
- `BATTLE`: 저장된 학습값을 읽되 변경하지 않는 평가 모드입니다.
- `REPEAT`: 경기가 끝나면 같은 세션에서 다음 에피소드를 시작합니다.
- `MAX`: 화면 갱신과 CSV 생성을 최소화하고 벽시계 대기를 없애 가능한 한
  빠르게 시뮬레이션합니다. MAX 화면의 초파리는 양쪽 시작점에 고정되지만
  표시되는 시뮬레이션 타이머와 에피소드 학습은 컴퓨터가 계산하는 속도로
  계속 진행됩니다. 1 ms 신경 계산과 50 ms 세계 갱신 간격 자체는 바뀌지
  않습니다.

## 커스터마이징의 의미

- 긴 검은 사거리가 늘지만 다음 공격 준비가 느려집니다.
- 빠른 날개는 이동 성능이 늘지만 스태미나 부담이 더 큽니다.
- 무거운 방패는 BLOCK/PARRY 기절을 늘리지만 들고 있을 때 이동·회전과
  스태미나에 불리합니다. PARRY 기절은 BLOCK보다 깁니다.
- 몸통·날개·검·방패는 각각 두 색 그라데이션을 고를 수 있습니다. 스킨과
  색은 외형만 바꾸며 물리 성능을 바꾸지 않습니다.

편집 미리보기, HUD 초상, 실제 경기 모델은 같은 저장값을 사용합니다.

## 파일을 구분해 주세요

- `.flypack`: 이름, 장비, 스킨, 두 색을 담은 공유 가능한 데이터 파일
- `.flytrain`: 학습된 readout 체크포인트. 개인 학습 상태이므로 기본적으로
  Git이나 공식 배포에 포함하지 않습니다.
- BANC cache / IO map: 원자료에서 로컬 생성하는 대용량 실행 데이터

`.flypack`은 DLL이나 스크립트를 실행할 수 없는 데이터 전용 형식입니다.

## 직접 빌드하려면

Windows, Visual Studio의 C++ x64 도구와 Windows SDK가 필요합니다.

```bat
build_v067.bat
test_v067_profile_learning.bat
```

성공하면 `bin\FlyArena-v0.6.7.exe`가 만들어집니다.

## 문제가 생기면

- 빌드 도구를 찾지 못함: Visual Studio Installer에서 Desktop development
  with C++와 Windows SDK를 설치합니다.
- BANC/IO 파일을 찾지 못함: 위의 두 준비 배치를 순서대로 실행합니다.
- MAX에서 화면이 뜸하게 보임: 정상입니다. 학습 계산에 자원을 집중하도록
  상태 확인용 heartbeat만 가끔 보냅니다.
- 버그 신고: 버전, 재현 순서, 오류 문구, GPU/Windows 정보를 적되 개인
  `.flytrain`, 계정 정보, 원본 BANC 데이터는 첨부하지 마세요.
